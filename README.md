# Визуализатор зависимостей Ubuntu APT

Практическая работа №2 по конфигурационному управлению. ИКБО-62-25, вариант 7.

## Этап 1. Конфигурация

Прототип на Python 3.10+ принимает путь к файлу JSON, проверяет семь полей и
печатает их в формате `ключ = значение`. Пути в JSON разрешаются от каталога
конфигурации.

```powershell
.\run.bat examples/local.json
python -m unittest discover -v
```

Тест `test_invalid_parameter_values` проверяет ошибки для каждого из семи
полей. Дополнительные проверки охватывают URL, отсутствующие, неизвестные и
повторяющиеся ключи.

## Этап 2. Прямые зависимости

В текущем CLI используется индекс `Packages.gz` из Ubuntu 24.04 LTS.
Программа читает `Depends` и `Pre-Depends`, включая альтернативы. Тесты
проверяют текстовый индекс и сжатие gzip и XZ через локальный HTTP-сервер.

```powershell
.\run.bat examples/ubuntu-hello.json
python -m unittest discover -v
```

Для демонстрации конфигурации переключитесь на тег `stage-1`.

## Этап 3. Транзитивный граф

DFS использует стек и хранит минимальную глубину обработки каждой вершины.
Если позже найден более короткий путь, вершина может открыть новые рёбра.
На предельной глубине вершины видны без исходящих рёбер. Пакеты, совпавшие с
`exclude_substring`, исключаются вместе с путями через них.

```powershell
.\run.bat examples/local.json
.\run.bat examples/local-limited.json
.\run.bat examples/local-isolated.json
```

`local.json` содержит циклы и повторное достижение вершины. В
`local-limited.json` удалён D, а E находится на предельной глубине.
`local-isolated.json` показывает один пакет Z. Этап 2 доступен по тегу
`stage-2`.
